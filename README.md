# 📦 카에루몰 스마트 창고 로케이션 & QR 관리 시스템

스마트폰 여러 대에서 동시에 접속하여 창고 선반(자리) QR과 상품 라벨지 QR을 스캔하고, 실시간으로 보관 위치를 저장 및 조회하는 모바일 친화적 웹 애플리케이션입니다.

---

## 🚀 주요 기능

1. **📱 모바일 QR 카메라 스캐너 (`/scanner`)**
   - 별도 앱 설치 없이 스마트폰 브라우저에서 바로 카메라 스캔 지원 (HTML5 QR Code)
   - 선반의 **[자리 QR]** 스캔 시 현재 위치 자동 고정 (예: `A-01`)
   - **[상품 라벨지 QR]** 스캔 시 접수번호(단건/다건) 및 고객명을 자동 파싱하여 해당 자리에 1초 만에 저장
   - 스캔 성공 시 오디오 비프음 및 진동 피드백

2. **🏷️ 자리(선반) QR 라벨 인쇄 (`/locations`)**
   - 창고 선반/랙에 부착할 자리용 QR 코드 라벨(예: `A-01`, `B-02` 등) 생성
   - 60x40mm 라벨 프린터(Xprinter) 및 일반 A4 출력 지원

3. **📋 실시간 재고 & 자리 검색 대시보드 (`/inventory`)**
   - 접수번호, 고객명, 또는 자리 코드로 현재 보관 중인 위치 실시간 검색
   - 보관 자리 이동 및 출고 완료 처리 기능 지원

---

## 💻 로컬 실행 방법 (PC)

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 서버 실행
python server_launcher.py
```

- **관리자 PC 접속:** `http://localhost:5000`
- **스마트폰 현장 접속:** 같은 Wi-Fi에 연결된 상태에서 `http://[PC_IP주소]:5000` 접속

---

## 🌐 클라우드 배포 (Render, Railway 등)
- `Procfile` 및 `requirements.txt`가 포함되어 있어 Render 또는 Railway에 레포지토리를 연결하면 무료로 즉시 HTTPS 배포가 가능합니다.
